Why the legs work this way: on a long (bullish) signal both legs become PE: sell ATM PE, buy the PE 300 pts lower (a bull put spread). On a short (bearish) signal both become CE: sell ATM CE, buy the CE 300 pts higher (a bear call spread). OTM 300 picks the correct side automatically. Leg SL and TP stay 0, because the stop-loss is set once in Risk Management (screen 3).

Fix from your screenshot: “SuperTrend Crosses Above SuperTrend” compares Supertrend with itself, so it never fires. Use Close Greater Than SuperTrend instead. Use “Greater/Less Than”, not “Crosses”, for every row. The algo enters on the first 15-minute candle where all six are true, and Max Trade Cycle = 1 stops a second trade.
If 1 Day / 1 Week intervals aren’t offered for rows 5–6, leave those rows out and set Transaction Type by hand each morning: Only Long when Nifty is above both this week’s and today’s open, Only Short when it is below both, and pause the strategy otherwise.
